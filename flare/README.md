# 🔥 FLARE (Funding & Liquidation Asymmetric Reversion Engine)

> **소액 자본(Small Capital)을 위한 펀딩비 & 청산 데이터 기반 단기 비대칭 역발상 엔진**

---

## 📌 1. 프로젝트 개요

* **배경**: 기존 메인 시스템인 `RADE`(1시간봉 HMM 기반)는 대자본 운용에 훌륭하지만, 소액 자본(100만 원 수준) 기준 회전율(월 3~4회) 및 절대 수익금의 한계가 존재함.
* **목표**: 차트 패턴(돌파/추세)을 버리고, 바이낸스 코인 선물 시장의 **수급 결함(극단적 펀딩비 & 강제 청산 꼬리)**을 착취하는 고승률 단기 알파 발굴.
* **검증된 핵심 원리**:
  1. **Funding Rate Reversion**: 펀딩비가 상/하위 5%로 치달았을 때, 24시간 내 반대 방향으로 평균 `+3.8% ~ +6.5%`의 큰 진폭(MFE)이 발생함 (p = 0.006).
  2. **Liquidation Confluence**: 펀딩비 과열 상태에서 5분봉 청산 꼬리(거래량 3배)가 터지는 순간 진입 시, **최악의 낙폭(Worst MAE)을 -16%에서 -3.7%로 극적 방어**하며 4시간 내 시간당 수익 속도가 2.5배 빨라짐.

## 🎯 2. FLARE 듀얼 운용 모드 (Dual Mode Specification)

FLARE 엔진은 트레이더의 성향과 자본 규모에 맞추어 **2가지 상호보완적 듀얼 모드**를 지원합니다:

| 항목 | 🟢 **Mode 1: FLARE-Swing (펀딩비 스윙)** | ⚡ **Mode 2: FLARE-Sniper (청산 저격 스캘핑)** |
|:---|:---|:---|
| **핵심 철학** | 펀딩비 극단 쏠림 후 24시간 동안 묵직한 큰 파이를 챙김 | 펀딩 과열 중 청산 빔 바닥을 확인 후 타이트한 칼손절로 저격 |
| **진입 트리거** | 8시간 펀딩비 정산 시점 (00:00, 08:00, 16:00) 과열 확정 시 | 펀딩 과열 유지 중 5분봉 거래량 3x + 긴 꼬리(55%+) 완성 시 |
| **타임 호라이즌** | **24시간 (288개 5분봉)** | **4시간 (48개 5분봉)** |
| **목표 익절 (TP)** | **`+2.5% ~ +3.5%`** (지정가 호가창 등록) | **`+1.2% ~ +1.5%`** (지정가 호가창 등록) |
| **방어 손절 (SL)** | **`-3.0% ~ -4.0%`** (서버 시장가) | **`-1.0% ~ -1.2%`** (서버 시장가, 낙폭 방어 🏆) |
| **손익비 (RR)** | 약 `1.3x ~ 1.5x` (평균 MFE +3.8% vs MAE 2.2%) | 약 `1.3x ~ 1.5x` (평균 MFE +1.4% vs MAE 0.8%) |
| **권장 레버리지** | **2배 ~ 3배** (넓은 하방 룸 대응) | **5배 ~ 8배** (좁은 하방 룸을 활용한 소액 복리 극대화 🏆) |
| **거래 빈도** | **연간 약 110회 (월 9~10회)** (BTC 기준) | **연간 약 48회 (월 4회)** (BTC 기준) |
| **강점** | 로직이 단순하고 관리가 편하며 1회당 수익 파이가 큼 | 지하실 폭락 위험(-16%)이 원천 차단되며 자본 회전율 2.5배 빠름 |
