[배경]
- 개인(펀드/기관 아님) 비트코인 선물 투자자, 소액 자본
- 기존 전략 1: HMM으로 국면(횡보/추세) 판단 → 횡보권은 평균회귀, 추세 국면은 상승 롱/하락 숏
- 기존 전략 2: 펀딩비 과열 구간 24시간 모니터링 → 손절/익절
- 두 전략 모두 거래 빈도가 매우 낮음(월 2회 이하인 경우도 있음)
- 세 번째 전략으로 SNS/뉴스 모니터링 기반 거래 프로그램을 구상 중
- 목표: 하루 최소 1회~최대 3회 거래 발생

[논의된 핵심 결론]
1. 순수 실시간 반응형(뉴스 뜨자마자 즉시 매매)은 기관과의 속도 경쟁이라 개인에게 불리함
2. 필터/보조 신호로 붙이는 방식은 기존 두 전략의 거래 빈도 문제를 오히려 악화시킴 → 독립 전략으로 설계하는 게 맞음
3. 거래 빈도를 늘리려면 "개별 콘텐츠의 정밀 해석"보다 "언급량·감성의 통계적 이상치(anomaly)" 자체를 신호로 삼는 방식이 유리함
   - 후보: (a) 언급량 z-score 기반 변동성 돌파 (b) 다계정 감성 집계 지수 (c) 멀티 키워드 범위 확대
4. 관련 학술 연구는 다수 존재하며 대체로 긍정적 결과를 보고하나(예: Garcia & Schweitzer 2015 - 연 200%대 수익, 샤프 1.82; M-DQN 2024 - 29.93% 수익, 샤프 2.7+), 발표 편향·과최적화 가능성을 감안해야 함
5. 발표 편향과 재현 가능성 문제는 같은 뿌리(과거 데이터에 대한 반복 튜닝 후 좋은 결과만 발표)를 공유하므로, 재현 가능성 검증이 핵심 과제
   - 검증 방법: (1) 논문 작성 시점 이후 데이터로 out-of-sample 테스트 (2) 파라미터를 소폭 변경해도 성과가 유지되는지 민감도 테스트
6. "하루 1~3회" 빈도는 임계값 조정으로 기술적으로는 쉽게 맞출 수 있으나, 빈도를 억지로 맞추면 노이즈성 신호가 섞여 수익성이 낮아질 위험이 큼 → 먼저 임계값을 널널하게 잡아 신호 품질(승률, 손익비)을 확인한 뒤 원하는 빈도로 좁혀가는 순서 권장
7. 냉정한 확률 평가: 기술적 구현 가능성은 높음(70~80%), 그 상태에서 실제 수익 가능성은 낮음~중간 수준으로 봐야 함

[비용 없이 시작하는 방법 - 추천 순서]
1순위: Kaggle 등에 공개된 과거 비트코인 트윗/감성 데이터셋으로 아이디어의 생존 가능성(out-of-sample, 파라미터 민감도)부터 무료로 검증
2순위: 신호가 살아있다면 RSS 피드(CoinDesk, CoinTelegraph 등, 무료·무제한) + 로컬 오픈소스 감성분석 모델(VADER, FinBERT)로 실시간 파이프라인 구축, 비용 0
병행: Alternative.me Fear&Greed Index(무료 API)를 벤치마크 기준선으로 함께 활용해, 직접 만든 감성분석이 기존 무료 지수 대비 우위가 있는지 비교
참고: Reddit API 무료 티어는 접근이 비교적 자유로움. X(트위터)는 무료 API 접근이 사실상 막혀 있어 초기 단계에서는 배제하는 것이 현실적

**무료로 시작 가능한 데이터 소스들**

1. **이미 만들어진 무료 감성/심리 지표 활용**
 - Alternative.me의 Fear & Greed Index는 무료 API로 제공되고, 이미 SNS·설문·변동성·거래량 등을 종합한 지수예요. 직접 감성분석 파이프라인을 만들기 전에, 이 기존 지수만으로 원하시는 "하루 1~3회 거래" 빈도와 수익성이 나오는지부터 테스트해보는 게 가장 빠른 시작점입니다.
 - LunarCrush, Santiment 같은 곳도 무료 티어(제한적 요청 횟수)로 소셜 볼륨/감성 데이터를 제공해요. 이걸로 초기 프로토타입을 돌려볼 수 있습니다.

2. **뉴스 RSS 피드 (완전 무료, 무제한)**
 - CoinDesk, CoinTelegraph 등 주요 크립토 매체는 RSS 피드를 무료로 제공합니다. 유료 뉴스 API 없이도 헤드라인 텍스트는 실시간으로 받아올 수 있고, 감성분석은 오픈소스 모델(VADER, FinBERT 등 로컬 실행 가능한 경량 모델)로 무료 처리 가능해요.

3. **Google Trends (pytrends)**
 - 완전 무료이고, 실제 여러 논문(Garcia & Schweitzer 등)에서 검색량 데이터가 가격에 선행하는 신호로 쓰였습니다. 다만 시간 해상도가 낮아서(시간 단위가 최선) 하루 1~3회 목표에는 다소 거칠 수 있어요.

4. **Reddit 무료 API**
 - r/Bitcoin, r/CryptoCurrency 같은 서브레딧은 Reddit API 무료 티어(요청 제한 있음)로 게시물·댓글 데이터를 가져올 수 있습니다. 트위터/X보다 접근이 훨씬 자유롭고 안정적이에요.

5. **과거 데이터셋으로 먼저 백테스트 (실시간 API 자체가 필요 없음)**
 - Kaggle에는 비트코인 관련 트윗/감성 데이터셋이 이미 여러 개 공개되어 있습니다(예: 2015~2021년 기간). 지난 대화에서 말씀드린 "out-of-sample 검증"과 "파라미터 민감도 테스트"를 이런 무료 과거 데이터로 먼저 해보면, 실시간 API에 돈을 쓰기 전에 아이디어 자체의 생존 가능성을 상당 부분 걸러낼 수 있어요.**추천 순서**

가장 효율적인 순서는 3 → 2/1 조합일 것 같아요. Kaggle 공개 데이터셋으로 먼저 "감성-가격 관계"라는 아이디어 자체의 로직이 지금도 살아있는지 out-of-sample 검증을 해보고, 만약 신호가 살아있다면 그때 RSS+로컬 감성분석(비용 0)으로 실시간 파이프라인을 만들어 페이퍼 트레이딩에 투입하는 방식입니다. Fear & Greed Index는 병렬로 벤치마크(비교 기준선)로 계속 같이 돌려보면, 나중에 "내가 직접 만든 감성분석이 기존 무료 지수보다 나은가"를 판단하는 데도 유용할 거예요.

한 가지 유의할 점은, X(트위터)는 API 정책이 자주 바뀌고 무료 티어가 사실상 거의 없어진 상태라 무료 경로로는 접근이 어려운 편이에요. 그래서 초기 검증 단계에서는 Reddit과 뉴스 RSS 중심으로 데이터를 확보하시는 게 현실적일 겁니다.
